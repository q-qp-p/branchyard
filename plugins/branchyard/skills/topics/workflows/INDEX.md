# Composed workflows

Coordinate section ownership and assemble deliverables.

[All topics](../../INDEX.md)

- [parallel-deck](../../parallel-deck/INDEX.md): Split a large presentation into independently owned section specifications and assemble checked editable slides with one renderer.
- [fan-judge](../../fan-judge/INDEX.md): Fan one task across several harnesses, then compare, judge and pick the best attempt within per-attempt budgets.
- [pr-feedback-loop](../../pr-feedback-loop/INDEX.md): Open a GitHub pull request for a ready branch and loop CI and review feedback back into it, stacking large changes, until merge.
- [budgeted-explore](../../budgeted-explore/INDEX.md): Run cost-bounded investigation with spending, turn and time limits, read-only access and stop rules.
- [issue-pr](../../issue-pr/INDEX.md): Turn tracker issues (GitHub, Linear, Jira, GitLab) into branches and linked pull requests.
